# E-Commerce Sales & Customer Insights Dashboard

## Project Overview
This project aims to analyze e-commerce sales data to derive customer insights and business intelligence. It utilizes the UCI Online Retail dataset to demonstrate data cleaning, analysis, and visualization techniques.

## Business Problem
Understanding sales performance, customer behavior, and product trends is crucial for e-commerce businesses. This project addresses the need for actionable insights that can drive strategic decisions.

## Objectives
- Clean and preprocess the raw sales data.
- Perform exploratory data analysis to uncover trends and patterns.
- Create a Power BI dashboard for interactive data visualization.
- Generate reports and insights for business stakeholders.

## Dataset
The dataset used in this project is the UCI Online Retail dataset, which contains transaction data from a UK-based online retailer. The dataset includes fields such as InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, and Country.

## Project Architecture
The project is structured into several directories for data, Python scripts, SQL scripts, Power BI files, Excel analysis, outputs, and documentation.

## Data Cleaning
The data cleaning process involves downloading the dataset, standardizing column names, handling missing values, and removing invalid entries. The cleaned data is saved in both CSV and SQLite formats.

## SQL Analysis
SQL scripts are provided to perform various analyses on the cleaned dataset, including sales, customer, and product analyses.

## Power BI Dashboard
A Power BI dashboard is created to visualize key metrics and trends, allowing stakeholders to interact with the data effectively.

## Excel Analysis
Excel analysis is performed to summarize key performance indicators (KPIs) and provide additional insights.

## KPIs
Key performance indicators include Total Revenue, Total Orders, Total Customers, Total Products, Average Order Value, and Total Quantity.

## Business Questions
The project aims to answer critical business questions such as:
- Which countries generate the highest revenue?
- Which products contribute most revenue?
- Which customers contribute significant revenue?
- Which months show higher sales?
